Inside every stall: the same six parts
1 · Start trigger
Player steps on the pad. Door and loadout lock.
→
2 · Timer
Counts the drill. Shown on the stall sign.
→
3 · Spawner
Bots and targets for the chosen tier.
→
4 · Scorer
Hits, time, eliminations. Compares to personal best.
→
5 · Feedback
Pass or fail on the sign and the HUD.
→
6 · Reset
Clears player pieces, respawns targets, unlocks door.
Naming and layout
One folder per level. Every device follows TG_<Level>_<Stall>_<Part>, for example TG_A_03_Timer. Build one template stall, then duplicate it and change only the spawner contents and the sign.
Player data
Per player: best score for each stall, highest bot tier cleared, last level visited. Use your editor's persistent storage so the hub can show progress. Device and storage names differ by editor version, so check them before building.
Suggested build order
1 Template stall · 2 Level A · 3 Hub and doors · 4 Levels B and C · 5 Levels D to F · 6 Tune bot tiers and pass marks with real players.
