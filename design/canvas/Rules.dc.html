Rule set · Space and sizing
Just enough room
Footprint = envelope + run-off
Envelope (teal) is the space the drill actually uses: where the player stands, builds and moves. Run-off is one extra tile around it so the player can back off or re-aim without hitting a wall. Anything bigger invites wandering. Anything smaller causes accidental fails.
Example: 1×1 box → 3×3 envelope → 5×5 stall

Unit reference
1 tile = 512 UU ≈ 5.12 m wide
Wall height 384 UU ≈ 3.84 m. Distances in this plan are tiles; metres are rounded. Confirm the grid values in your editor before placing anything.
No-ambiguity checklist
1 · One drill per box. Solid walls on every side except the single door.
2 · Printed start and goal. Floor decals mark the start line, the target line and the build limit.
3 · Build volume. Building is only allowed inside the stall footprint. Everywhere else is no-build.
4 · Height ceiling. An invisible kill plane at the drill's maximum height.
5 · Auto reset. Finishing or leaving a stall clears every player piece and respawns targets.
6 · Closed sightlines. Bots and targets only see and hit the stall's own player.
7 · One sign per stall. Task, metric and pass mark, readable from the start line.
