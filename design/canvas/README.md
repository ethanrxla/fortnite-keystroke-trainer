# Training Ground canvas (source)

Source files of the Design canvas "Training Ground Map" (published at
https://claude.ai/artifact/6HKMSrW9bWmPv7fGVLf1J2). Each `*.dc.html` is one artboard and
`canvas.json` is the layout index. These are snapshots from 2026-10-07; the published canvas is
the live copy and may have been edited since, so read it before relying on these.

The written spec is `../training-ground-spec.md`. The canvas shows footprints and lane layouts only.
