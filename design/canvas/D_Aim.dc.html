Door
White line = shoot line. Rings = targets. 5 tiles ≈ 25 m.
Props and devices
Loadout dispenser with infinite ammo at each shoot line. Targets are hit-scored props or dummies on a rail. Glass dividers between lanes so a neighbour never blocks your shot. No building in this level.
Bots
Lane 3's mover is a scripted dummy on a rail, not AI, so the pattern is repeatable: slow strafe, fast strafe, then stop-start. Other lanes use static or pop-up targets.

Why the lanes match
Every lane uses the same shoot line and the same 25 / 50 / 100 m marks, so a number means the same thing everywhere.
Run flow
1 Stand on the shoot line. 2 Press the lane button. 3 A three-second countdown, then targets appear. 4 Score shows on the lane sign. Leaving the line cancels the run.
